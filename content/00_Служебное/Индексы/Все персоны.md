# Сводный указатель персон

> [!info] Памятка
> Список формируется автоматически из папки `01_Персоны`. Новые добавленные родственники появятся здесь сразу после заполнения их карточки.

```dataview
TABLE 
  Фамильная_ветка as "Фамильная ветка",
  Дата_рождения as "Родился",
  Место_рождения as "Место рождения",
  Отец as "Отец",
  Мать as "Мать"
FROM "01_Персоны"
SORT file.name ASC
```
