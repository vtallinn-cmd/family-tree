Пока окно терминала открыто, локальный сайт работает. Закрываешь окно — сервер останавливается.

Это необязательная проверка после каждого изменения. 
Можно пользоваться ею, когда хочешь посмотреть, как материал будет выглядеть на сайте, до публикации

После изменений в Obsidian открываешь GitHub Desktop, проверяешь список изменений, 
делаешь Commit и нажимаешь Push origin.
Commit — зафиксировать выбранные изменения в локальной истории проекта. 
По сути, сохранить контрольную точку с описанием того, что изменилось.
Например, ты добавила статью о предке и несколько фотографий. GitHub Desktop покажет изменённые и новые файлы. 
Внизу слева ты пишешь краткое описание, например Добавлена статья о семье Шиндлеров, и нажимаешь Commit to v5.

После этого нажимаешь Push origin. 
Только тогда изменения попадут на GitHub и запустится публикация сайта.

GitHub Actions автоматически обновляет сайт.
